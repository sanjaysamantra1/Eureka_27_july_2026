How Javascript Works
====================
-When a JavaScript program runs, 1 Global Execution Context (anonymous) is created.
-For every function call, a new Function Execution Context (FEC) is created.
-Execution Context = the environment in which code executes.
-Each execution context has two phases: 
	1. creation phase. 
           a. memory is allocated for all variables(var,let,const)
           b. 'undefined' value is assigned to 'var' variables
	2. execution phase. (Code is executed line by line; variables receive their assigned values and functions are invoked)

Function Declaration  vs  Function Expression
=============================================
1. Function Declarations are named , Function Expressions are anonymous
2. Function Declarations are hoisted , Function Expressions are not hoisted
