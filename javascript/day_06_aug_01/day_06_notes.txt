Arrow Function 
==============
-Shorter in syntax
-Anonymous
-are not hoisted
-function keyword is not used
-function body is optional
-return is optional


this
====
-'this' is a keyword
-'this' refers to the object that is executing the current code


Arrow Function Limitations
==========================
1. arrow functions shoudn't be used as object methods
2. arrow functions shouldn't be used as event listeners


Arrow Function benefits
=======================
-uses 'this' value from lexical scope
-Lexical Scope : immediate outer scope / the scope where the function is written



Closure
=======
-an inner function retains access to its outer function's variables even after outer functions execution is completed.
-closure will not be seen for outer functions.
-closure will be seen for inner functions only if inner function accesses outer functions data


Why Closure
===========
-Data Encapsulation

Data Encapsulation = Data Hiding + allow to access  the data using member function
